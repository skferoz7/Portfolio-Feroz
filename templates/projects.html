Automated Public Lighting System (IoT)

The Automated Public Lighting System is an IoT-based smart street-lighting solution designed to minimize energy consumption and reduce manual intervention. The system uses LDR sensors to automatically control street lights based on ambient light.

Key Features
  • Automatic light control using LDR sensors
  • Energy-efficient and cost-effective
  • Low maintenance and autonomous operation
  • Scalable for smart city applications
